# Security Policy

OpenDumpling is a community fork of HashiCorp Boundary v0.13.1. Security
reports for the fork are handled by the OpenDumpling maintainers.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems. Instead,
use GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Provide a description, the affected version/commit, and a reproduction if
   possible.

If private reporting is unavailable, contact the maintainers listed in the
repository's organisation profile.

We will acknowledge receipt as soon as possible and coordinate a fix and
disclosure.

## Scope

This policy covers the OpenDumpling codebase in this repository. Vulnerabilities
that exist only in upstream HashiCorp products, or in the upstream web admin UI
(which is not included here), should be reported to the respective upstream
project.
