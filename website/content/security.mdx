# Security

We apply best practices and focus on security to make sure we can maintain the
trust of the community.

We deeply appreciate any effort to disclose vulnerabilities responsibly.

If you would like to report a vulnerability, please follow the process in the
[security policy](https://github.com/opendumpling/opendumpling/blob/main/SECURITY.md),
which describes how to reach us and which versions receive security fixes.

If you aren't reporting a security sensitive vulnerability, please
open an issue on the standard [GitHub](https://github.com/opendumpling/opendumpling)
repository.
