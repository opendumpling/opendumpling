# Dumpling v0.5.0

The release notes below contain information about new functionality available in Dumpling v0.5.0.
To see a granular record of when each item was merged into the Dumpling project, please refer to the [Changelog](https://github.com/opendumpling/opendumpling/blob/main/CHANGELOG.md).
To learn about what Dumpling consists of, we highly recommend you start at the [Getting Started Page](/docs/getting-started).

For guidance on which versions can be mixed during an upgrade, refer to [Version compatibility](/docs/operations/version-compatibility).

## Dumpling v0.5.0 highlights

**Event Logging:** 0.5.0 includes significant improvements to Dumpling's event logging system with goal of giving operators greater visibility into system information in a well-defined, structured format.
When enabled, event logs are the only type of logging Dumpling performs, meaning standard system information and debug logs will no longer appear in stdout.
The new structured event logs are filterable by event type and other expressions that users define. Legacy HCLog output is still supported through a user-configurable setting.

For more about event logging usage, see our [documentation](/docs/configuration/events).

**Credential CRUD operations for Administrative Console:** The 0.5.0 release enables administration to configure Vault credential libraries and Vault credential set resources through the administrative console.
Vault credential resources allows users to create Dumpling sessions with credentials brokered by a Vault deployment.
