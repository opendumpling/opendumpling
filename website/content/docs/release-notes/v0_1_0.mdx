# Dumpling v0.1.0

v0.1.0 is the first release of Dumpling. As a result there are no changes, improvements, or bugfixes from past versions. To learn about what Dumpling consists of, we highly recommend you start at the [Getting Started Page](/boundary/docs/getting-started).

## Dumpling v0.1.0 highlights

In this initial release, Dumpling provides:

- Password-based authentication
- Authenticated and authorized [TCP-based sessions](/boundary/docs/common-workflows/manage-sessions).
- Identity and access management providing [role-based controls](/boundary/docs/common-workflows/manage-roles) for principals.
- A user interface for administration of Dumpling resources.
- A [Terraform provider](https://github.com/hashicorp/terraform-provider-boundary) for managing Dumpling resources.
- A fully instrumented command line interface for managing Dumpling and for establishing and managing sessions.
- A fully instrumented [Dumpling golang SDK](/boundary/docs/api-clients/go-sdk).
- A log of Dumpling sessions exposed through Dumpling's administrator UI and postgres database.
