# Dumpling v0.11.0

The release notes below contain information about new functionality available in the Dumpling v0.11.0 release. To see a granular record of when each item was
merged into the Dumpling project, please refer to the [Changelog](https://github.com/opendumpling/opendumpling/blob/main/CHANGELOG.md). To learn about what Dumpling
consists of, we highly recommend you start at the [Getting Started Page](/docs/getting-started).

For guidance on which versions can be mixed during an upgrade, refer to [Version compatibility](/docs/operations/version-compatibility).

## Dumpling v0.11.0 highlights

**Private Vault access:** You can integrate an on-premises instance of Vault without having to publicly expose it, by deploying a Dumpling worker
in the same private network as the Vault instance. See [Vault workers](/docs/concepts/filtering/worker-tags).

**SSH credential injection:** SSH targets can be configured for credential injection so that credentials are never exposed to the user.

**Improved worker management:** Administrators can register and manage Dumpling workers and view session counts,
IP addresses and release versions of all registered workers through the CLI and the API.

**Support for Generic Credentials:** Dumpling now supports brokering of 'generic credentials'. This will enable users to broker any kind of key/value pair type
credentials when they are connecting to a remote host.
