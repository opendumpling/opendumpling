# Dumpling v0.8.0

The release notes below contain information about new functionality available in the Dumpling v0.8.0 release.
To see a granular record of when each item was merged into the Dumpling project, please refer to the [Changelog](https://github.com/opendumpling/opendumpling/blob/main/CHANGELOG.md).
To learn about what Dumpling consists of, we highly recommend you start at the [Getting Started Page](/docs/getting-started).

For guidance on which versions can be mixed during an upgrade, refer to [Version compatibility](/docs/operations/version-compatibility).

## Dumpling v0.8.0 highlights

**Metrics and Health Endpoint:** Dumpling is adding [Prometheus metrics](/docs/operations/metrics) to monitor the operations of workers and controllers,
as well as a [health endpoint](/docs/operations/health) for controllers.

**Audit Event Logs:** We are expanding the audit event logs by increasing the captured [audit events](/docs/configuration/events),
with support for sanitizing sensitive information from audit events. All of the events are now classified and events contain more usable data, with sensitive information redacted by default.

**Worker Tags:** Users can now set and edit [worker tag](/docs/concepts/filtering/worker-tags) filters when configuring workers.

**Performance Improvements:** We have implemented changes to improve performance on larger deployments,
such as response times when listing sessions and targets. We plan to continue these efforts as Dumpling users grow their deployments!
