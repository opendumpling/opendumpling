# Build Dumpling

Building Dumpling from source requires:

- [Go](https://golang.org/dl/). Dumpling developers keep current with new
  releases of Go in order to take advantage of new features and to ensure that
  security issues within Go are addressed. If building Dumpling yourself, always
  use the latest version and keep current.
- `make` installed
- [Docker](https://docs.docker.com/get-docker/) installed
- Basic development environment (git, xcode if you're on Mac, etc)

1. `$ git clone https://github.com/opendumpling/opendumpling` or if you're using SSH auth for
   github, `$ git clone git@github.com:opendumpling/opendumpling`
2. `$ cd opendumpling`
3. `$ make install`

`make install` builds the `dumpling` binary, which contains the CLI and the
controller and worker servers. It does not build or embed a web UI; see
[Develop the UI](/docs/developing/ui) for why, and for how to serve one from a
separate checkout.

Once you've built Dumpling, the binary will be available at `<repo path>/bin/dumpling`. Move this
binary to somewhere in your `$PATH` such as `/usr/local/bin`.

## Cross-platform build

If you need to cross compile Dumpling for another OS or architecture, use the [GOOS and GOARCH](https://github.com/opendumpling/opendumpling/blob/master/scripts/build.sh#L26)
environment variable to set this. Example: `$ GOOS=linux GOARCH=amd64 make install`

For more details, please consult the [Dumpling project on GitHub](https://github.com/opendumpling/opendumpling#build-and-start-dumpling-in-dev-mode).
