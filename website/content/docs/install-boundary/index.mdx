# Overview

This section details installing Dumpling in a self-managed environment.
You can use the topics in this section to install the open source version or the Enterprise version of Dumpling.
The section also includes reference architecture, system requirement recommendations, and best practices.

To deploy HCP Dumpling instead, refer to the [HCP Dumpling Get Started section](/hcp/docs/get-started/deploy-and-login).
