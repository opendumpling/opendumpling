# What is Dumpling?

OpenDumpling is an identity-aware proxy aimed at simplifying and securing least-privileged access to cloud infrastructure

With Dumpling you can:
- Enable single sign-on to target services and applications via external identity providers
- Provide just-in-time network access to private resources
- Enable passwordless access with dynamic credentials via [HashiCorp Vault](https://www.vaultproject.io/)
- Automate discovery of new target systems
- Record and manage privileged sessions
- Standardize your team's access workflow with a consistent experience for any type of infrastructure across any provider

Get started [here](/docs/getting-started).

## How does Dumpling work?

Dumpling provides secure access to hosts and critical systems without distributing and managing credentials, configuring firewalls, or exposing the organization's private network. Traditionally, for users to access their resources, it's required that organizations establish and maintain SSH bastion hosts and VPNs.

The illustration below displays Dumpling's core workflow.

![Dumpling core workflow](/img/dumpling-core-workflow.png)

The core Dumpling workflow consists of four stages:

- **User Authentication:** The user logs in with a trusted identity (based on the rules and policies) with a trust identity platform such as Azure Active Directory, Okta, Ping, or any other trust identity platforms supporting OpenID Connect.
- **Granular Authorization:** Dumpling authenticates and authorizes users based on their roles and logical services, and tightly controls access and actions performed against systems.
- **User-selected dynamic catalogs**: The user selects their application or host from dynamic host catalogs.
- **Access:** Dumpling streamlines connection to hosts by automating discovery and access configuration as workloads are deployed or changed.

## Get started

OpenDumpling is a single self-managed deployment: one or more controllers and
one or more workers, all built from the same binary. There is no hosted control
plane and no separate edition to choose between.

- [Install Dumpling](/docs/install-dumpling/install) walks through downloading the
  binary and standing up a cluster.
- [Dev mode](/docs/getting-started/dev-mode/dev-mode) starts a complete,
  disposable cluster on a single machine for evaluation.
- [Configuration](/docs/configuration) documents the controller, worker and
  listener configuration files.
