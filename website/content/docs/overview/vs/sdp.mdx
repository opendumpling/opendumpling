# Dumpling vs. software-defined perimeter

Software-defined perimeter (SDP) solutions secure access to applications and infrastructure based on user identity.
Dumpling is fundamentally an SDP solution that takes a zero trust approach to security design for system access; access to services is granted based on the scoped identity and intent of a user.
Dumpling is a scalable proxy that enables identity-based access with multiple layers of security controls including dynamic credentials, context-based access, [automated host discovery](/docs/concepts/host-discovery), and [access auditing](/docs/concepts/auditing) to name a few.
