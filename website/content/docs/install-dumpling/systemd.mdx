# Install Dumpling under systemd

This section covers how to install Dumpling under the [systemd](https://systemd.io/) init system on modern Linux distributions. In this section, we'll cover an example of breaking out the controller and worker servers onto separate instances, though you can opt to run both on a single server.

## Filesystem configuration

`TYPE` below can be either `worker` or `controller` if you want to run them independently, e.g. for high availability. If you want to run combined nodes, modify as desired.

1. `/etc/dumpling-${TYPE}.hcl`: Configuration file for the Dumpling service.

2. `/usr/local/bin/dumpling`: The Dumpling binary, which can be built from the [source](https://github.com/opendumpling/opendumpling) or downloaded from our [release page](https://github.com/opendumpling/opendumpling/releases).

3. `/etc/systemd/system/dumpling-${TYPE}.service`: Systemd unit file for the Dumpling service.

## User and group configuration

We recommend running Dumpling as a non-root user and using this user to manage the Dumpling process running under systemd. The example init files here do exactly that. Our example install script below creates a user and group on Ubuntu or Debian-like systems.

## systemd unit file

```
[Unit]
Description=${NAME} ${TYPE}

[Service]
ExecStart=/usr/local/bin/${NAME} server -config /etc/${NAME}-${TYPE}.hcl
User=dumpling
Group=dumpling
LimitMEMLOCK=infinity
Capabilities=CAP_IPC_LOCK+ep
CapabilityBoundingSet=CAP_SYSLOG CAP_IPC_LOCK

[Install]
WantedBy=multi-user.target
```

## systemd all-in-one installation script

Here's a simple install script that creates the `dumpling` group and user, installs the
systemd unit file, and enables it at startup:

```
#!/bin/bash
# Installs Dumpling as a service for systemd on linux
# Usage: ./install.sh <worker|controller>

TYPE=$1
NAME=dumpling

sudo cat << EOF > /etc/systemd/system/${NAME}-${TYPE}.service
[Unit]
Description=${NAME} ${TYPE}

[Service]
ExecStart=/usr/local/bin/${NAME} server -config /etc/${NAME}-${TYPE}.hcl
User=dumpling
Group=dumpling
LimitMEMLOCK=infinity
Capabilities=CAP_IPC_LOCK+ep
CapabilityBoundingSet=CAP_SYSLOG CAP_IPC_LOCK

[Install]
WantedBy=multi-user.target
EOF

# Add the Dumpling system user and group to ensure we have a no-login
# user capable of owning and running Dumpling
sudo adduser --system --group dumpling || true
sudo chown dumpling:dumpling /etc/${NAME}-${TYPE}.hcl
sudo chown dumpling:dumpling /usr/local/bin/dumpling

# Make sure to initialize the DB before starting the service. This will result in
# a database already initialized warning if another controller or worker has done this
# already, making it a lazy, best effort initialization
if [ "${TYPE}" = "controller" ]; then
  sudo /usr/local/bin/dumpling database init -config /etc/${NAME}-${TYPE}.hcl || true
fi

sudo chmod 664 /etc/systemd/system/${NAME}-${TYPE}.service
sudo systemctl daemon-reload
sudo systemctl enable ${NAME}-${TYPE}
sudo systemctl start ${NAME}-${TYPE}
```
