# Get started

This section walks through how to get started with Dumpling. You’ll learn how
Dumpling provides secure access to private endpoints.

OpenDumpling is a single self-managed distribution: you run the controllers and
workers yourself, in your own environment. There is no hosted offering and no
separate edition, so the only choice is how much of a cluster you want to stand
up at once.

- **[Dev mode](/docs/getting-started/dev-mode/dev-mode)** starts a complete,
  disposable cluster on a single machine, including a controller, a worker, a
  database, and some example resources. This is the fastest way to try Dumpling
  and to develop against it.
- **[Install Dumpling](/docs/install-dumpling)** walks through deploying a
  production cluster, starting from the
  [Recommended architecture](/docs/install-dumpling/recommended-architecture).

## Key concepts

Before getting started with Dumpling, it's important to understand a few key
concepts. Please consult our [Dumpling concepts](/docs/concepts) page to
familiarize yourself with Dumpling's architecture and terminology.
